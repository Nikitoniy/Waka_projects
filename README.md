## Проекты в компании Waka

Проекты посвящены автоматизации обработки и подготовки данных для последующего анализа. Основная задача — сократить объём ручной работы, привести данные к единому формату и структурировать их для дальнейшего использования в аналитике.

### 1. [Обработка и структурирование данных о продажах](https://colab.research.google.com/github/Nikitoniy/Waka_projects/blob/main/%D0%95%D0%B6%D0%B5%D0%BC%D0%B5%D1%81%D1%8F%D0%BD%D1%8B%D0%B9_%D0%BE%D1%82%D1%87%D0%B5%D1%82.ipynb)

Разработал скрипт для автоматизации подготовки данных о продажах. Приводил названия товарных позиций к единому формату, нормализовал числовые обозначения и исправлял распространённые ошибки в названиях брендов и моделей. Автоматизировал извлечение бренда, модели и вкуса в отдельные поля, а также очистку данных от нерелевантных товарных категорий. Результатом стала структурированная таблица, готовая для дальнейшего анализа продаж.

### 2. [Географический анализ торговых точек](https://colab.research.google.com/github/Nikitoniy/Waka_projects/blob/main/%D0%9F%D0%BE%D0%B8%D1%81%D0%BA_%D0%BC%D0%B5%D1%82%D1%80%D0%BE_%D0%B8_%D1%81%D1%82%D0%BE%D1%80%D0%BE%D0%BD_%D1%81%D0%B2%D0%B5%D1%82%D0%B0.ipynb)

Автоматизировал обработку адресов торговых точек и определение их географического положения. Нормализовал адреса с помощью DaData, получал координаты через API Яндекс Геокодера, а затем рассчитывал расстояние до ближайшей станции метро на основе географических координат. Дополнительно определял сторону света относительно центра города для каждой торговой точки. Результатом стала структурированная таблица с адресами, координатами, ближайшими станциями метро и направлением сторон света от центра города.
